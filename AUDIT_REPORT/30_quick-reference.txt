ATTACK SURFACE ANALYSIS
=======================

Attack Vector 1: MIME Type Spoofing
  Example: Upload .php file with Content-Type: image/jpeg
  Mitigation: ✓ Static serving (Node.js, no PHP execution)
  Residual Risk: LOW (vulnerable to header spoofing, safe in context)
  Recommendation: Add magic byte validation for defense-in-depth

Attack Vector 2: File Size DoS
  Example: Upload 100 GB file
  Mitigation: ✓ 2 MB size limit enforced
  Residual Risk: NONE

Attack Vector 3: Path Traversal
  Example: Filename: ../../../etc/passwd
  Mitigation: ✓ Server assigns UUID (ignores client input)
  Residual Risk: NONE

Attack Vector 4: Double Extension
  Example: shell.php.jpg
  Mitigation: ✓ Server assigns .jpg only
  Residual Risk: NONE

Attack Vector 5: Null Byte Injection
  Example: shell.php%00.jpg
  Mitigation: ✓ Server assigns UUID.jpg
  Residual Risk: NONE

Attack Vector 6: Unauthenticated Upload
  Example: POST without token
  Mitigation: ✓ requireAuth middleware
  Residual Risk: NONE

Attack Vector 7: Non-Admin Upload
  Example: Authenticated user (not admin)
  Mitigation: ✓ requireAdmin (DB-verified)
  Residual Risk: NONE

Attack Vector 8: Multipart Bomb
  Example: 1000 form fields with overhead
  Mitigation: ✓ .single('image') rejects extra fields
  Residual Risk: NONE
